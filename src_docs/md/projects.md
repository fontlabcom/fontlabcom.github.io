# Projects

Public repositories in the [fontlabcom](https://github.com/fontlabcom)
organization on GitHub.

## Documentation

### FontLab Python API

Reference documentation for scripting FontLab in Python, built with
ProperDocs from the API itself.

- [FontLab 7 Python API](https://code.fontlab.com/fontlab-python-docs/)
- [PythonQt API](https://code.fontlab.com/fontlab-python-docs/pythonqt/)
- Source: [fontlabcom/fontlab-python-docs](https://github.com/fontlabcom/fontlab-python-docs) (Apache-2.0)

## Extensions

### Extend FontLab

A catalogue of extensions, scripts, plugins and templates for the FontLab font editor.

- Website: [extend.fontlab.com](https://extend.fontlab.com/)
- Source: [fontlabcom/extend-fontlab](https://github.com/fontlabcom/extend-fontlab) (Apache-2.0)

## Fonts

### GetGo Fonts for FontLab

Font files to start your own font projects in FontLab. They are licensed
under CC-0, Apache or OFL, and come in the FontLab VFJ format.

- Website: [GetGo Fonts](https://code.fontlab.com/getgo-fonts/)
- Source: [fontlabcom/getgo-fonts](https://github.com/fontlabcom/getgo-fonts)

### FlexLab

A customized, slimmed and subset version of Roboto Flex.

- Source: [fontlabcom/flexlab-font-ofl](https://github.com/fontlabcom/flexlab-font-ofl) (OFL-1.1)

## Tools and libraries

### QtPy

FontLab's fork of [QtPy](https://github.com/spyder-ide/qtpy), the
abstraction layer that lets one codebase run on PyQt5, PySide2, PyQt4 and PySide.

- Source: [fontlabcom/qtpy](https://github.com/fontlabcom/qtpy) (MIT)

### Made with FontLab gallery tool

An internal tool that builds the “Made with FontLab” gallery.

- Source: [fontlabcom/flweb_mwf_gallery](https://github.com/fontlabcom/flweb_mwf_gallery) (MIT)
